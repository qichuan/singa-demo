# Singapore Planet: web build

Playable build of **Singapore Planet**, a tiny walkable 3D Singapore in the browser. Source:
https://github.com/qichuan/little_planet_sg (built with `npm run build`).

- Fully static: open `index.html` from any web server (GitHub Pages works as is). three.js is bundled, no CDN needed.
- Desktop: WASD / arrows to walk, Shift to run, E to talk, M for the map, drag to look, wheel to zoom.
- Phone / tablet: on-screen joystick (push to the edge to run), tap prompts to talk, drag to look, pinch to zoom.
  Graphics start on Low on touch devices; switch in ⚙️ Settings. "Add to Home Screen" runs it full screen.

3D models by [Kenney](https://kenney.nl) (CC0), see `assets/kenney/LICENSE-Kenney-CC0.txt`.
